### 1. ฟีเจอร์และการใช้งาน (Features)

| หมวดหมู่ระบบ | ฟีเจอร์หลัก | รายละเอียดการทำงาน |
| ------------- | ------------- | ------------- |
| **Dashboard & Analytics** | - สรุปยอดเงินเรียลไทม์<br>- หลอดงบประมาณ<br>- กราฟวิเคราะห์ | แสดงรายรับ รายจ่าย ยอดคงเหลือ พร้อมกราฟวงกลมแยกหมวดหมู่และกราฟแท่งดูแนวโน้มย้อนหลัง 6 เดือน |
| **Transaction Management** | - บันทึก/แก้ไข/ลบ<br>- ตัวกรองประวัติ<br>- นำเข้า/ส่งออก (CSV) | จัดการรายรับ-รายจ่ายได้อย่างรวดเร็ว กรองดูข้อมูลตามเดือนได้ และรองรับการดึงข้อมูลเข้า/ออกผ่านไฟล์ Excel |
| **Financial Planning** | - จัดสรรงบตามหมวดหมู่<br>- เป้าหมายการออม | ตั้งเพดานรายจ่ายแต่ละหมวด และสร้างกระปุกออมสินดิจิทัลที่มีหลอดความคืบหน้าพร้อมคำนวณยอดฝากต่อเดือน |
| **Bills & Recurring** | - บิลและแจ้งเตือน<br>- รายการประจำ | แจ้งเตือนบิลล่วงหน้าก่อนครบกำหนด และตั้งค่ารายการซ้ำ (เช่น เงินเดือน, ค่าไฟ) ให้ลงบันทึกอัตโนมัติ |
| **Security & UI** | - ระบบล็อกรหัสผ่าน<br>- ล็อกอัตโนมัติ<br>- ธีมมืด (Dark Theme) | ปกป้องข้อมูลส่วนตัวด้วยรหัสผ่าน และออกแบบหน้าตาโปรแกรมให้สวยงาม สบายตา อ่านข้อมูลตัวเลขได้ชัดเจน |


### 2. โครงสร้างสถาปัตยกรรม (System Architecture)

| โครงสร้างระบบ | ไฟล์ที่รับผิดชอบ | หน้าที่การทำงาน |
| ------------- | ------------- | ------------- |
| **Core & Controller** | `Main.java`, `Stats.java` | ศูนย์กลางควบคุมหน้าจอทั้งหมด และคอยคำนวณตัวเลข สรุปยอดทางบัญชี |
| **UI & Utilities** | `Ui.java`, `Charts.java` | ควบคุมโทนสี (Dark Theme) ทั่วทั้งโปรแกรม วาดกราฟ และจัดการสไตล์ |
| **Dialogs** | `BillDialog.java`, ฯลฯ | หน้าต่างย่อยที่เด้งขึ้นมาให้กรอกข้อมูลเฉพาะส่วน เพื่อไม่ให้หน้าจอหลักดูรก |
| **Data Models** | `Transaction.java`, ฯลฯ | โครงสร้างที่กำหนดว่าข้อมูลแต่ละรายการต้องมีรายละเอียดอะไรบ้าง |
| **Data Persistence** | `Filemanager.java` | คอยรับข้อมูลจากหน้าจอไปบันทึกลงไฟล์ และดึงข้อมูลจากไฟล์ขึ้นมาแสดง |
| **Database** | ไฟล์ `.txt` ต่างๆ | แฟ้มจัดเก็บข้อมูลทั้งหมดที่บันทึกไว้ในเครื่องคอมพิวเตอร์ของคุณ |
